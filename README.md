## 🚀 Project Overview

This project analyzes global happiness trends using the **World Happiness Report (2015–2023)** dataset.

It explores how economic, social, and health factors affect happiness across countries.

---

### 💡 Key Insights

- 🌍 GDP strongly correlates with happiness
- 🤝 Social support plays a major role in well-being
- 🧠 Freedom impacts national happiness levels
- 📉 Some regions show persistent inequality in happiness scores

---

## 📊 Dashboard Features

The dashboard allows users to:

- 🌍 Compare countries & regions
- 📈 Track happiness trends over years
- 🔍 Explore correlations between variables
- 📊 Analyze distributions of indicators
- 🎛️ Interact using filters & controls
