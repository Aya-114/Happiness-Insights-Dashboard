## 🚀 Project Overview

This project explores the factors that influence **global happiness levels** using the World Happiness Report dataset (2015–2023).

The dashboard allows users to:

- 🌍 Compare happiness across countries and regions  
- 📈 Analyze trends over time  
- 🧠 Explore relationships between economic & social factors  
- 📊 Visualize distributions of happiness indicators  
- 🔍 Identify key drivers of happiness  

---

## 📊 Dataset

The project uses a cleaned dataset stored in:

```text id="data1"
data/cleaned_data.csv
````

Built from multiple yearly World Happiness Report CSV files.

### 📌 Features:

* Country
* Year
* Happiness Score
* GDP per Capita
* Social Support
* Life Expectancy
* Freedom
* Generosity
* Corruption Perception
